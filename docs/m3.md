## Known limits

- **Clamping devices re-trigger a rule.** A readable type that clamps a requested value continues to differ from the rule's desired value and is written every tick. Back-off is left for a follow-up; pulse mode uses the desired value's edge and has different semantics.
- **Coroutine counts are partial.** Up to **999 instructions per thread** are uncounted. Task 8's script ran about **80×** its budget; the supplied review script with many short coroutines ran about **166×**. Neither script was re-run here; the factor depends on the script. The chip's `xpcall` first rethrows a spent budget before invoking its error handler, a deliberate deviation from stock Lua-CSharp to prevent an unmetered continuation.
- **Sleeping/resumable ticks are not modelled.** The ordinary Lua coroutine library is available; the game's `yield`, `sleep`, resumable tick and claimed 32 sleeping user coroutines await P15 and its documentation.
- **Devices rows are paged.** A square 480 × 480 design page shows three roles per page. PREV/NEXT navigate roles; a row cycles candidates and SAVE commits the pick. Appearance belongs to the console author.
- **The integer-format warning is heuristic.** `format(...)` plus `%d`/`%i` anywhere in that expression/custom text triggers it, so an unrelated Lua pattern can warn. A lexer over format-call string arguments would refine it.
- **String-state mirrors can split a surrogate pair.** Memory stores three UTF-16 units per address, with a default string limit of 30 units. Truncation at that boundary can leave half a supplementary character; the memory mirror is not a Unicode-safe unlimited store.
- **Large `all` roles consume the real tick budget.** The measured approximately 127 instructions per device/read workload and 49k rename scan leave little room for other work at the sizes above. Faster scanning does not remove the read cost.
- **Two pointer paths are absent.** `OnDrag` scrolling inside a scroll container and `OnBeginDrag`'s free-cursor dragstart are not ported. Other drag event forms do not imply those paths work.
- **Unmeasured host rows remain provisional.** P17 beta vector removal has no probe statement; P5b save/reload timing was not run; cross-surface commit scope, missing-device writes, writable slots and the physical-pointer debounce/event cap remain unprobed. P8 is out of scope and Task 21 dropped. The measured P1–P7, P9–P14 and P16 answers are recorded above. An unreadable boot store disables writes for the session; a 120-tick retry remains conditional on P5b.
- **Synthetic italic remains approximate.** The DOM uses the browser's oblique synthesis, rather than TMP's per-glyph centred **0.35** shear. The supplied Canvas measurement proxy observed about **0.25** shear and up to **10.66 px** difference at a **100 px** font. That proxy was not re-run here; a whole-run skew cannot establish TMP glyph-quad fidelity.
- **Faux bold under thick outlines is incomplete.** Its dilation is not yet reduced under thick outlines; the correction awaits the vector mod's fixed outline formula.
- **Outline width differs from the current game.** The preview draws a label's `ow` as documented, while the game currently draws it about **1.8× wider**. This is a reported upstream defect; the builder follows the documented width.
- **Translucent covers retain the M2c limit.** They blend text in sRGB (M2c's reported roughly 30 channel levels darker at alpha 0.5). Late-face loads now refresh dependent labels only, but their current browser latency was not measured here.
- **Bundle and catalogue limits are visible.** The main chunk exceeds the 900 kB warning. The catalogue tags 169 export-only devices as mod unless the vanilla list says otherwise; 227 extension LogicType names lack numbers and are dropped until an enum probe supplies them. Deprecated enum names remain selectable.
- **Export checks belong to M4.** Offline fixture execution establishes those fixtures' behaviour, not a pre-export check of every user's script. Renaming an id leaves Lua expression text for the user to update. The UI remains a functional prototype.

## How to run it

Use Node 24 with npm and .NET SDK 10.0.401 or newer. From a clone with initialized submodules, these PowerShell commands build the local preview and run the checks; `VectorSrc` must resolve to the absolute vector-submodule path, ending in `/`.

```powershell
git clone --recurse-submodules <repository-url>
Set-Location <repository-folder>
# Existing clone: git submodule update --init --recursive
dotnet workload install wasm-tools wasm-experimental
$vectorSrc = (Resolve-Path core/vendor/vector).Path.Replace('\', '/') + '/'
dotnet run --project core/Core.Tests "-p:VectorSrc=$vectorSrc"

# Publish into an empty output folder after core changes.
Remove-Item -LiteralPath core/Wasm/bin/publish -Recurse -Force -ErrorAction SilentlyContinue
dotnet publish core/Wasm -c Release "-p:VectorSrc=$vectorSrc" -o core/Wasm/bin/publish
Set-Location web
npm.cmd ci
npm.cmd run precore
npm.cmd test
npm.cmd run build
npm.cmd run dev
```

Open the local URL printed by the server. Use Logic for roles/reads/state/actions/rules, Data for bindings, Sim for device values/settings, and Custom Lua for hooks. Play sends events to the generated script; Edit restores canvas editing. Download or Copy exports it. For long submodule paths on Windows, initialize with long-path support as described in [M2c](m2c.md#how-to-run-it).

Refresh or check the catalogue from the repository root, with the owner's Stationpedia export and device list kept outside the repository:

```powershell
node tools/catalog/build.ts --export <export-folder> --md <device-list>
node tools/catalog/build.ts --export <export-folder> --md <device-list> --check
# Add --values <enum-values-json> once the optional enum probe supplies observed numbers.
```

To run the regeneration test, set its two input variables and invoke it from `web` (this is the command run once for this report):

```powershell
$env:VB_CATALOG_SRC = '<export-folder>'
$env:VB_CATALOG_MD = '<device-list>'
npx.cmd vitest run src/catalog/catalog.test.ts -t 'regenerates the committed JSON'
# Set VB_CATALOG_VALUES too if the committed enums record observed probe values.
```
